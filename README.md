## 📊 Featured Projects

### 🛒 Brazil E-Commerce Analytics Warehouse

End-to-end analytics project using **Snowflake, SQL, Power BI, and DAX** on the Olist Brazilian E-Commerce dataset.

Highlights:

- Built a layered **RAW → STAGING → ANALYTICS** architecture in Snowflake
- Designed fact and dimension tables for analytical reporting
- Created separate fact tables for orders, order items, and payments
- Built customer **RFM segmentation**
- Analyzed customer retention, category performance, logistics, and reviews
- Built multi-page Power BI dashboards
- Used Snowflake RBAC, resource monitors, internal stages, and cost controls

Tech:
**Snowflake | SQL | Power BI | DAX | Power Query**
